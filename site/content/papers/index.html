后端配置

Agent 阶段不走 API key，而是直接调用已登录的 Claude Code CLI。

AGENT_BACKEND=cli_agent
CLI_AGENT_COMMAND=claude
CLI_AGENT_MODEL=claude-sonnet-5
CLI_AGENT_ARGS=["--effort","medium",
  "--dangerously-skip-permissions",
  "--add-dir","{workspace}","--print"]
CLI_AGENT_OUTPUT_FORMAT=json
AGENT_TIMEOUT_SECONDS=900
