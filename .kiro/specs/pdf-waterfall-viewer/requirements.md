# 论文阅读器（EmbedPDF）— 需求

## 背景与方向变更

`site/` 是无后端静态站，18 份论文解构报告放在 `site/downloads/`（共 32MB）。

第一版方案是"卡片 → 单篇预览页（PDF.js 自绘 canvas）"。实际用起来的问题是每篇都要跳一次页面，
且自绘阅读器要自己补懒渲染、文本层、跳页这些浏览器本就有的能力。改为：

**一个常驻阅读页 = 左侧按主题分层的目录 + 右侧 EmbedPDF 阅读区，选中即在原地换文档。**
布局参考 MkDocs Material 的 `md-nav` 分层侧栏；阅读器用 [EmbedPDF](https://github.com/embedpdf/embed-pdf-viewer)（PDFium/WASM）。

原 `site/viewer.html`（PDF.js）已删除，不再维护两套阅读实现。

## 需求

### R1 分层目录浏览
- 侧栏**应当**按主题分组展示全部论文，组可折叠，显示每组篇数。
- 未登记进分组表的论文**应当**仍然出现（落到「未分组」），不允许因为漏登记而从站上消失。
- 侧栏**应当**带关键词筛选（标题、副标题、标签），命中为空的组自动隐藏。

### R2 原地切换 + 多标签
- 点击侧栏条目**不应**整页刷新，右侧直接换成对应 PDF。
- 点开一篇**应当**在阅读器内部新开一个标签，多篇可同时开着来回跳；已开过的同一篇**不应**重复开。
- 标签文案**应当**是论文标题，而不是内部 id。
- 切换**应当**走 `pushState`，浏览器后退回到上一篇。
- `reader.html?paper=<slug>` **应当**是可分享、刷新后仍定位到同一篇的稳定 URL。

### R2b 版式、全屏与关闭标签
- 默认**应当**双栏（跨页）显示，并按宽度适配（fit width），跨页横向铺满阅读区。
- **应当**提供全屏；全屏状态下仍能通过左侧目录换论文。
- **应当**能关闭当前内部标签（按钮 + 快捷键），且关闭语义是"关标签"而不是"关浏览器页"；
  `Ctrl+W` 在平台允许的前提下（Windows/Linux Chrome 全屏）也走同一动作。
- 阅读页**不应**保留站头，纵向空间全部给目录与阅读区。

### R2c 侧栏可调
- 侧栏宽度**应当**可拖动调整，并可整体收起把宽度让给阅读区。
- 宽度与收起状态**应当**在刷新后保持。
- 调宽后阅读区**应当**重新按整页适配。

### R3 阅读能力
- 正文**应当**可选中、可复制、可搜索（由 PDFium 文本层提供）。
- 初次打开**应当**直接看到页面内容，而不是报告的大片上边距。
- **应当**始终保留"新标签打开"与"下载 PDF"，阅读器不是唯一取文件的路径。
- **应当**展示论文原文链接（arXiv / DOI / 原文）等元数据；流水线没抽到链接时**应当**可手工补齐。

### R4 加载与降级
- 阅读器运行时（约 6MB）**应当**只在第一次真正点开某篇论文时才加载；只浏览首页的访客不承担这份流量。
- 运行时加载失败或初始化异常时**应当**自动退回浏览器自带 PDF 阅读器，页面不能停在空白。
- 第三方来源**应当**收敛到 jsdelivr 一个，不额外请求 Google Fonts 等。

### R5 首页瀑布流不抖动
- 封面卡片**应当**按封面真实比例预留空间，图片加载前后不发生位移。

### R6 与流水线解耦
- 侧栏分组表**应当**存放在 `scripts/build-papers-page.py` 重写范围之外，重跑流水线不会丢失分组。
- `npm run validate` **应当**校验阅读器文件存在、封面齐备，并对未分组论文给出提示（提示，不失败）。

## 验收（本轮已实测）

用 `agent-browser`（Chrome）在本地静态服务上验证：

| 项 | 结果 |
| --- | --- |
| 侧栏结构 | 5 组 / 18 条 |
| 深链打开 `?paper=attention-all-you-need` | 标题、副标题、下载链接正确，文档渲染 |
| 点击侧栏切换到 `simai` / `gpemu` / `torchfx` | URL 变为 `?paper=<slug>`，标题与高亮同步，无 console 错误 |
| 多标签 | 开两篇 → 两个标签（`GPEmu`、`Torch.fx`）；再点已开的那篇 → 标签数不变，直接切过去 |
| 双栏 | 首屏并排显示第 1、2 页 |
| 全屏 | 点「全屏」→ `document.fullscreenElement === #readerShell`，shell 高度等于 `innerHeight`，按钮变「退出全屏」 |
| fit width | 跨页宽 963px ≈ 阅读区 984px，缩放 80%，页面 477×675 |
| Alt+W / 「关闭标签」按钮 | 两标签下关当前 → 切到另一篇（URL/标题/高亮同步）；再关 → 空态、URL 无 `?paper=`、按钮 disabled |
| `navigator.keyboard`（macOS Chromium） | 无头与 headed 均为 `false` → `⌘+W` 无法拦截，已改用按钮 + `Alt+W` |
| 去站头 | 无 `.site-header`，shell 从 y=0 起吃满 639px，阅读区从 505px 涨到 572px |
| 侧栏拖宽 | 拖到 380px → 刷新后仍是 380px（`localStorage`）；方向键两次 → 348px |
| 侧栏收起/展开 | 收起后阅读区 984→1274px，再点恢复 290px；按钮文案 `⇤/⇥ 目录` 同步 |
| 原文链接 | `tally` 显示 `arXiv:2410.07381 ↗` → `https://arxiv.org/abs/2410.07381` |
| 第三方请求 | 只有 `cdn.jsdelivr.net`（4 个请求），无 fonts.googleapis.com |
| 首屏内容 | FitPage，打开即见标题页 |
| 首页卡片链接 | `reader.html?paper=<slug>`，论文页为 `../../reader.html?paper=<slug>` |
| 封面比例 | 361×509（0.709），与封面产物 339×480（0.706）一致，无形变与位移 |

## 不在范围内

- 服务端、检索、全文索引。
- 台账页 `content/papers/index.html` 的表格口径与生成逻辑。
- 已发布 PDF 的 slug 变更。
- 阅读器运行时的自托管（vendored）——见 design 的开放项。
